«Готуємось до старшої профільної» — вебзастосунок (PWA)

ЯК РОЗМІСТИТИ
Покладіть усю папку на хостинг як є (index.html має лежати в корені папки).
Обов'язково HTTPS — без нього встановлення на телефон не працює.

  • Netlify: app.netlify.com/drop → перетягніть цю папку.
  • Сайт МОН: передайте папку вебкоманді; можна розмістити в підпапці, напр. /navigator/.

ЯК ВСТАНОВИТИ НА ТЕЛЕФОН
  • iPhone (Safari): «Поділитися» → «На початковий екран».
  • Android (Chrome): кнопка «Встановити» внизу сторінки або меню ⋮ → «Встановити застосунок».

ЯК ОНОВЛЮВАТИ
Замініть index.html, а у файлі sw.js змініть VERSION (напр. 'profilna-v2'),
щоб телефони підхопили нову версію.

ФАЙЛИ
  index.html              — сайт (посібник уже вбудований)
  manifest.webmanifest    — назва, кольори, іконки застосунку
  sw.js                   — робота без інтернету
  icons/                  — іконки для iOS, Android і вкладки браузера
